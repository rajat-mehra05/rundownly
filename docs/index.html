Installation

  1. Download the .dmg file above
  2. Open the .dmg and drag to Applications
  3. If you see “damaged and can’t be opened”, open Terminal and run:
    xattr -cr /Applications/Rundownly.app
  4. Enter your Anthropic API key when prompted
  5. Paste a YouTube URL and hit Summarize!
Note: macOS may show a “damaged” or “unidentified developer” warning. This is normal for free open-source apps that aren’t code-signed. The xattr -cr command removes the quarantine flag added by your browser.
  1. Download the .msi installer above
  2. Run the installer
  3. If SmartScreen appears: click “More info” → “Run anyway”

Note: Windows SmartScreen may warn about an unrecognized app. This is normal for open-source software without a paid code-signing certificate.
